# لندینگ تجمیع برق خورشیدی برقتو

**Persian RTL landing page for solar power aggregation and electricity sales.**

> **وضعیت:** پروژه آزمایشی طراحی و توسعه رابط کاربری است؛ ادعای استقرار عملیاتی، کاربران واقعی یا صحت تجاری ارقام ندارد.

## معرفی

این مخزن یکی از طرح‌های وب‌سایت برقتو برای معرفی تجمیع برق خورشیدی و تجربه فارسی راست‌به‌چپ است. هر مخزن یک پیاده‌سازی/نسخه مستقل از رابط کاربری را نگهداری می‌کند.

## قابلیت‌ها

- معرفی مزایای تجمیع برق نیروگاه خورشیدی و بازار برق سبز
- ماشین‌حساب تخمینی درآمد نیروگاه (ظرفیت و نوع اتصال)
- فرم بررسی رایگان همراه با اعتبارسنجی سمت مرورگر
- آکاردئون پرسش‌های متداول، شمارنده‌ها و انیمیشن‌های تعاملی

## ساختار مخزن

- `index.html` — صفحه اصلی و بخش‌های محتوا
- `styles.css` — طراحی واکنش‌گرا و راست‌به‌چپ
- `script.js` — محاسبه‌گر، فرم، FAQ و جلوه‌ها
- `barghto-landing.html` — نسخه مستقل تک‌فایلی برای پیش‌نمایش

## اجرای محلی

پیش‌نیاز: یک مرورگر جدید؛ برای مدیریت درست مسیرها بهتر است یک سرور استاتیک محلی داشته باشید. از ریشه مخزن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. به Build پیچیده یا Node.js نیازی نیست. 

## نکات مهم

- ضرایب محاسبه‌گر و اعداد نمایشی، نمونه هستند و بدون تأیید نرخ‌های جاری نباید به‌عنوان پیشنهاد مالی استفاده شوند.
- ارسال اطلاعات شخصی، انتشار آمار عملکرد واقعی یا معرفی نرخ‌های بازار منوط به اتصال بک‌اند و تأیید داده‌هاست.
- قبل از بازنشر تصاویر، فونت‌ها و منابع بیرونی، مجوز استفاده را بررسی کنید.
- این مخزن بخشی از نمونه‌کارهای توسعه وب برقتو است و پروژه `smart-energy-city` مستقل از آن است.
