# برقتو — لندینگ تجمیع‌کننده برق نیروگاه‌های خورشیدی

لندینگ تک‌صفحه‌ای RTL فارسی برای «برقتو»؛ تجمیع‌کننده‌ای که برق نیروگاه‌های خورشیدی را بالاتر از قیمت خرید تضمینی دولت در بازار برق می‌فروشد.

## بخش‌ها
- هیرو با دو CTA («محاسبه درآمد نیروگاه» و «بررسی رایگان شرایط همکاری»)
- معرفی آیین‌نامه جدید
- ماشین‌حساب تخمین درآمد (ظرفیت kW/MW + نوع آنگرید/هیبرید)
- فرم بررسی رایگان
- جدول مقایسه «چرا برقتو؟»
- سکشن ویدیو
- ۴ کارت آمار عملکرد
- سوالات متداول (آکاردئون)

## فایل‌ها
| فایل | توضیح |
|------|-------|
| `index.html` | ساختار صفحه (نقطه ورود) |
| `styles.css` | استایل RTL و ریسپانسیو |
| `script.js` | منطق ماشین‌حساب، آکاردئون و اعتبارسنجی فرم |
| `barghto-landing.html` | نسخه تک‌فایلِ مستقل (CSS/JS داخلی) برای باز کردن آفلاین |

## اجرا
فایل `index.html` را در مرورگر باز کنید، یا یک سرور ساده اجرا کنید:

```bash
python3 -m http.server 8080
```

سپس به `http://localhost:8080` بروید.

> ضرایب ماشین‌حساب و اعداد کارت‌های آمار تخمینی‌اند و در بالای `script.js` و در `data-target`ها قابل ویرایش‌اند.
